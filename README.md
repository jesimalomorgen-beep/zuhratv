# ZuhraTV

Einfache TV-Oberfläche für bosnische Sender – für den Internet-Browser des Fernsehers (z. B. Samsung).

**Adresse:** http://tv.orionluxembourg.lu  (wichtig: **http**, nicht https – der IPTV-Server kann kein https)

## Start am Fernseher
Einfach **http://tv.orionluxembourg.lu** im TV-Browser öffnen – der Zugang ist vorbelegt.

Anderen Zugang einmalig per Adresse setzen:

    http://tv.orionluxembourg.lu/#BENUTZER:PASSWORT

## Bedienung
- Sender anklicken (oder ▲▼ + OK) = Bild rechts
- Nochmal anklicken / OK = Vollbild, Zurück = Senderliste
